# Personal Expense Tracker

A simple desktop-based Personal Expense Tracker developed using Python, Tkinter, and SQLite.

## Features

- Add new expenses
- View all expenses
- Search expenses by title or category
- Delete selected expenses
- Calculate total expenses
- View current month's expenses
- View transaction count
- Monthly expense summary
- Input validation
- SQLite database storage

## Technologies Used

- Python
- Tkinter
- SQLite
- SQL
- Git & GitHub

## How to Run

### 1. Open the project folder

Open the project in VS Code.

### 2. Run the application

Open the terminal and run:

python main.py

### 3. Use the application

After running the command, the Personal Expense Tracker window will open.

You can:

- Add expenses
- Search expenses
- Delete expenses
- View monthly summary
- Check total expenses

## Expense Categories

## Database

The application uses SQLite for storing expense records.

Each expense contains:

- ID
- Title
- Amount
- Category
- Date
- Created timestamp

## Validation

The application validates:

- Empty fields
- Expense title
- Expense amount
- Date format
- Future dates
